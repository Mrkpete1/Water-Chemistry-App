Water Chemistry Assistant PWA v4

Adds contextual test training:
- Calcium screen: How to Test Calcium Hardness video
- Alkalinity screen: How to Test Total Alkalinity video
- pH screen: How to Test pH video
- Bromine screen: How to Test Bromine video
- Daily log has direct Bromine and pH training buttons.
- Weekly log has direct Alkalinity and Calcium training buttons.
- Videos open in an in-app modal so the operator returns directly to the reading entry.
- Daily/weekly screens show the most recent recorded test.

Existing features remain: fresh-fill gated workflow, routine testing, custom volumes, facilities, history, daily/weekly logs, CSV export, weight + approximate volume dosing.
