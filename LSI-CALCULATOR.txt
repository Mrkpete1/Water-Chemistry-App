HOW TO USE
Select the pool and open LSI Calculator. Available pH, temperature, TA and
calcium readings load only from that pool. Dates are shown; readings may come
from different dates. Confirm or replace them with current measurements.
Enter measured TDS and CYA. Enter 0 CYA only if confirmed absent. No TDS/CYA
values are guessed. Dichlor can contribute CYA in a bromine pool.
Calculate LSI. Results below -0.3 indicate calcium-carbonate-dissolving tendency;
-0.3 through +0.3 is the commonly accepted pool range; above +0.3 indicates
scale-forming tendency. This is not a direct metal-corrosion or sanitation test.
Use it after fresh-fill balancing, during weekly testing, following major
water/temperature changes, or to investigate recurring scale.

METHOD
Base-10 logs. Temperature T is kelvin, converted using degrees C + 273.15.
Corrected alkalinity = total alkalinity - CYA/3.
A = (log10(TDS) - 1)/10
B = -13.12 * log10(T) + 34.55
C = log10(calcium hardness as CaCO3) - 0.4
D = log10(corrected alkalinity as CaCO3)
pHs = 9.3 + A + B - C - D
LSI = measured pH - pHs
This approximate Carrier/Langelier calculation can differ from rounded lookup
charts and more complete carbonate saturation models. CYA/3 is approximate;
borates and other alkalinity contributors are not corrected. Classification
uses the unrounded result, displayed to three decimal places.
